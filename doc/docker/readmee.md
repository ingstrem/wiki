Устанавливаем необходимые зависимости:

`apt-get install apt-transport-https ca-certificates curl gnupg lsb-release`

Для того чтобы предоставить пользователю Ubuntu права на управление Docker, нужно добавить этого пользователя в группу docker. Это позволит пользователю запускать команды Docker без необходимости использовать sudo.

Вот шаги, которые нужно выполнить:

1. Добавление пользователя в группу `docker`:

`sudo usermod -aG docker $USER`

Здесь $USER — это имя текущего пользователя. Если вы хотите добавить другого пользователя, замените $USER на нужное имя.

2. Выход из системы и повторный вход:
   После добавления пользователя в группу docker, вам потребуется выйти из системы и снова войти, чтобы изменения вступили в силу. Либо можно перезапустить сессию терминала.

Теперь пользователь сможет управлять Docker без использования sudo.
