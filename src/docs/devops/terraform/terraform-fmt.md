# Terraform fmt

<time>{{time}}</time>

---

Команда `terraform fmt` в Terraform автоматически форматирует конфигурационные файлы в соответствии с единым стилем. Она корректирует отступы, выравнивает аргументы и сортирует блоки и аргументы в алфавитном порядке. Команда перезаписывает конфигурационные файлы Terraform (.tf и .tfvars) в текущем каталоге и его подкаталогах. Она используется для поддержания единого стиля кодирования в разных проектах и ​​командах, улучшая читаемость и уменьшая конфликты слияния. Команду можно запускать с такими параметрами, как `-recursive` для форматирования файлов в подкаталогах, `-diff` для отображения различий или `-check` для проверки форматирования без внесения изменений. Регулярное использование `terraform fmt` считается лучшей практикой в ​​рабочих процессах разработки Terraform.
