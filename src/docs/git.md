# Система контроля версий Git

> {{caption }}

---

Система контроля версий (VCS) — это инструмент, помогающий разработчикам управлять изменениями в коде с течением времени. Она позволяет одновременно существовать нескольким версиям проекта, упрощая сотрудничество с другими и ведение учета всех изменений.
